## Featured

### [Karkia Tarabar Asia](https://github.com/MH-Honarvar/karkia-landing-page) — کارکیا ترابر آسیا

International logistics landing for road, rail, air, and sea. The public page is Persian first, with English and Russian. Static HTML on `main`: one page, Vazirmatn and Inter, images, and SEO for the live domain. Visitors can ask for a rate by form, phone, or WhatsApp. The quoted rate comes after the route is checked. That line is the page’s own description, not a claim about a backend.

- Live: [karkiatarabar.com/landing](https://karkiatarabar.com/landing/)
- Also on Pages: [mh-honarvar.github.io/karkia-landing-page](https://mh-honarvar.github.io/karkia-landing-page/)

### [mh-honarvar.github.io](https://github.com/MH-Honarvar/MH-Honarvar.github.io) — سایت شخصی

Personal site in Persian and English. Astro and TypeScript, with a Three.js scene, GSAP, and Lenis. Locale routes are separate. The blog is written twice, once in each language, on type, RTL, the first screen, and when not to animate. Search is Pagefind on the built site. Pinned on this profile.

- Live: [mh-honarvar.github.io](https://mh-honarvar.github.io/)
